0|FANUC CNC Macro Training
1|This training teaches Custom Macro B from scratch, using the milling macro library (O1611 to O1636), each one explained block by block with a drawing.
2|How to study this training
3|The training follows the same order as the macros in the <b>MACROS_CNC.zip</b> package. Each macro has: what it does, the drawing, the G65 call with the letter table, the code explained block by block and the precautions at the machine.
4|<b>Recommended order</b>
5|Chapters 1 to 6 (basics): read them once, calmly. This is the part that gives you control.
6|Chapter 7 (face milling): it is the simplest macro. Run it in the machine simulator or in the air before moving on.
7|Chapters 8 to 16: one macro at a time, in the order you will use them day to day.
8|Chapter 18: first-part checklist. Always follow it.
9|Chapters 19 and 20: exercises and answers. It only counts as training if you try before looking.
10|<b>Standard used in all macros</b>
11|Main program <code>O00xx</code> (what the operator edits) and subprogram <code>O16xx</code> (the macro, do not touch).
12|The subprogram comments say what each letter and each variable does.
13|The origin is always stated in the comment (center or corner of the part).
14|Invalid values raise a numbered <code>#3000</code> alarm, instead of the machine doing something wrong.
15|<b>Important warning</b>: the programs were checked in toolpath simulation, not on your machine. Available variables, offset numbering (<code>#10001</code>, <code>#12001</code>) and permanent variables (<code>#500+</code>) depend on the FANUC series and setup. Always run the first time in the air, with reduced feed and one hand on the stop button.
16|1. What a macro is
17|A <b>macro</b> is a subprogram that accepts <b>values</b>. Instead of writing one program for a 100 x 100 face and another for 215 x 215, you write <b>a single program</b> and give the sizes in the call.
18|Flow: the main program calls the macro with G65 and comes back with M99
19|The path is always the same:
20|The main program runs the line <code>G65 P1611 X215. Y215. ...</code>.
21|FANUC jumps to program <code>O1611</code> and hands over the typed numbers (X, Y, Z...) in variables.
22|The macro does the math and the moves using those variables.
23|At <code>M99</code> it gives control back to the block right after the G65.
24|<b>Everyday comparison</b>: the macro is a cake recipe with blanks ("how many cups of ___"). The G65 is you filling in the blanks and handing the recipe to the cook.
25|<b>Why use a macro instead of fixed G-code</b>
26|Change the size in seconds, without recalculating anything.
27|The same code works for different parts.
28|The control does the math you would do on a calculator (sine, cosine, passes) by itself.
29|Fewer typing errors: the math is always done the same way.

44|2. Variables
45|A variable is a <b>numbered drawer</b> with a number inside. Written as <code>#</code> followed by the number. Example: <code>#100 = 25.</code> puts 25 in drawer 100. Then <code>G1 X#100</code> is the same as <code>G1 X25.</code>.

67|<b>Golden rule of the library</b>: in macros that call another macro (for example O1612 calls O1613), the common <code>#100+</code> variables are <b>shared</b>. That is why O1612 uses only <code>#27</code> to <code>#32</code> (free locals), so it does not mess up the math of the called macro.
68|<b>Empty vs zero</b>: a variable that was never used is <i>empty</i> (<code>#0</code>). In many calculations it counts as zero, but in <code>EQ</code> comparisons empty and zero can give different results. That is why the program always assigns a value before using it.

158|5. Decisions and loops
159|Without decisions, the macro would only be a calculator. With decisions it <b>repeats</b> blocks (loops) and <b>chooses</b> paths.
160|<b>IF ... THEN</b> (a single action)
161|If Q was not given, Q gets the feed value. If the condition is false, the line is skipped.
162|<b>IF ... GOTO</b> (jumps to a block with N)
163|If the condition is true, the control goes to block <code>N10</code>. If it is false, it goes on to the next line.
164|<b>GOTO</b> without a condition: <code>GOTO 30</code> always jumps.
165|<b>The loop (repetition) in 4 steps</b>
166|Repetition loop with IF GOTO
167|The counter starts at 1.
168|At <code>N10</code> it does the work (one hole, one pass, one turn).
169|Add 1 to the counter.
170|Ask: "is there more to do?" If yes, <code>GOTO 10</code>; if not, go on.
171|<b>Full example (4 holes in a line, spacing 20)</b>
172|Loop: #100=0 → X0. #100=1 → X20. #100=2 → X40. #100=3 → X60. Then #100=4, the condition fails and it exits. That is <b>4 holes</b>.
173|<b>Classic mistakes</b>
174|Forgetting to add to the counter: the loop never ends. Press RESET.
175|Using <code>LT</code> when <code>LE</code> was needed: one hole is missing.
176|Jumping to an <code>N</code> that does not exist: N not found alarm (<code>P/S 128</code>, depends on the series).
177|Using the same <code>N</code> number twice in the macro: it goes to the first one.
178|<b>WHILE ... DO ... END</b>
179|Does the same as IF/GOTO and is easier to read, but <b>the library uses IF/GOTO</b> because it works on every FANUC, old and new.
180|6. Alarms and messages
181|Every macro starts by validating the numbers. If something is wrong, the machine <b>stops before cutting</b>.
182|<code>#3000 = 101</code> raises a macro alarm. The number and the text in parentheses show on the screen. On most FANUC controls the number shown is 3000 + 101 = 3101 or just the text. <b>Depends on the series/setup.</b>
183|<code>#3006 = 1 (MESSAGE)</code> stops the program with a message, waiting for the operator to press cycle start.

185|Macro

190|<b>How to read the alarm on the shop floor</b>: read the text, go back to the macro's letter table and check the typed number. It is almost always a forgotten letter, a wrong sign or a cutter that is too big.

401|12. Macros 5 and 6: Outside profiles in a spiral (O1616 and O1617)
402|<b>What they do</b>: profile the outside of a rectangular part with a corner radius (O1616) or a regular polygon (O1617: square, hexagon, octagon...). The tool <b>goes down a little on each side</b>, without stopping, in a spiral. The last turn is flat to remove the spiral mark.
403|Spirals: the step down happens while profiling
404|<b>Why a spiral and not layers?</b> There is no exit and entry mark on each layer, and rapid time goes down.
405|<b>Direction</b>: clockwise (G2) around the part with the cutter turning M3 = <b>climb</b> milling.

464|The radius curve is a quarter circle. 702|17.1 Common idea of radii and chamfers on round parts
703|They all make full turns with G2 or G3, one per position, going down or up following the profile. On each turn the macro calculates the radius of the cutter center path and the Z. The smaller the step (letter H in degrees for radii, letter Q for chamfers and cones), the smoother the finish and the longer the program.
704|<b>Outside convex radius (O1635)</b>: cutter center radius = D/2 - C + C·SIN(θ) + T/2 and Z = W - C + C·COS(θ).
705|<b>Concave radius at the base (O1636)</b>: cutter center radius = D/2 + C - C·COS(φ) + T/2 and Z = Z + C - C·SIN(φ). Roughing must leave material in the corner.
706|<b>Hole chamfer (O1628)</b>: the corner of the flat end mill follows a line from the top to the wall; each turn steps Q / TAN B on the radius. Alarm 267 if C is larger than T.
707|17.2 Outside cone with an angle letter (O1630)
708|With a flat end mill any angle B from 1 to 89 degrees is possible: the cutter starts at the small diameter and goes to the large one in helical turns (letter Q sets the height of each pass). With a conical chamfer mill the angle is limited to 45 degrees to the face (alarm 286). The step left between turns can be up to Q high, so use a small Q for finishing.
709|17.3 Specific precautions
710|Letters used in macros called inside other macros must not overlap: check the table before combining. When D and I are used together in the same call, test in the air and check the values.
711|An empty letter is not zero: the macro uses <code>EQ #0</code> to test it. If you want zero, write the letter with 0.
712|In all radius and chamfer macros, the cutter must have a sharp corner; a cutter with a corner radius changes the path.
713|Check the length offset of the tip (or the corner) used as reference before running.
714|18. How to test without breaking anything: first-part checklist
715|<b>Before running</b>
716|Are the O16xx subprograms loaded in memory and do they open without errors?
717|Does the G65 call have <b>all</b> the letters in the table, with a decimal point?
718|Right origin: center or corner of the part depending on the macro (see the subprogram comment).
719|G54 and tool offset H checked. Does the top Z (W) match the part?
720|Right cutter: diameter T equal to what was typed, center cutting (helix, pockets), sharp corner (radius), 90° (chamfer).
721|M3 spindle direction and coolant on.
722|<b>First run: in the air</b>
723|Raise Z: add 50 mm to W and to Z (for example W50 and Z40) so the cutter passes above the part.
724|<b>Single block</b> mode (SINGLE BLOCK) and feed at 20 to 50%.
725|Look at the path/graphics screen, if there is one, and compare the drawing with the chapters of this training.
726|Watch the <b>distance to go</b> on the screen (DIST TO GO) before each first move.
727|Hand on the stop button (FEED HOLD) during the first moves.
728|<b>Second run: cutting, on a test part</b>
729|Set W and Z back to the real values.
730|Run with a small K (first layer) and check the result with calipers.
731|Only then go up to the final values.
732|<b>Useful tricks</b>
733|Want to stop when something shows up? <code>#3006 = 1 (CHECK)</code> on the line before that section makes a pause.
734|To simulate in the air, raise W and Z by the same amount (Z stays below W, no alarm).
735|<b>Other edges of a part</b>: the simplest way is to use side V1 and the Y of the other side (radius and chamfer). For edges at other angles, you can rotate the coordinate system with <b>G68</b> (if the option exists), but test first. Depends on the FANUC series/setup.
